# Legacy Wealth Platform

Premium dark-luxury public website for Legacy Wealth.

Current build: responsive marketing site, investment and Trading Academy sections, illustrative package examples with risk disclosure, Supabase email/password authentication UI, and GitHub Pages deployment workflow.

Connected Supabase project: Investment Platform (EU West). Only the publishable browser key is used in the frontend.

Next production modules: member dashboard, KYC, deposits, investments, withdrawals, immutable ledger, receiving accounts, withdrawal destinations, notifications, support, admin RBAC/CMS, audit logs, security and compliance review.
